# Figures

Both figures are generated by `../R/02_analyze.R` from the saved snapshots and cleaned data.

| File | Used in the post | Description |
|---|---|---|
| `starting_rents.png` | “Which areas fit the budget?” | Starting monthly base rent for each eligible property, with a $1,500 reference line |
| `rent_per_sqft.png` | “Comparing space per dollar” | Starting rent divided by listed square footage for properties reporting one exact floor-plan area |

Run `source("run.R")` from the `post2` folder to regenerate both files.
