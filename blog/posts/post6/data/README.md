# Data files

`family_members.csv` and `income_panel.csv` are generated by `python3 src/run_analysis.py` from a fixed random seed. They are included so you can inspect the inputs before rerunning the workflow.

- `family_members.csv`: one row for each parent and child, with `person_id`, shared `family_id`, and `role`.
- `income_panel.csv`: one row per person-year, with `person_id`, `year`, `age`, and positive simulated annual income.

These are simulated teaching data, not observations from PSID or another survey. The generator and all modeling assumptions are in `src/run_analysis.py`.
